NFA ShotGrid for 3DEqualizer

3DEqualizer 8.1 connected to ShotGrid: start 3DE from ShotGrid Desktop, and your tracks open and save in the right place with the right name — just like in Maya, Houdini and Nuke.

Starting

Always start 3DE from ShotGrid Desktop, preferably from your task (for example Matchmove on a shot). That way 3DE knows which shot you are working on. If you start 3DE from the Start menu, there is no ShotGrid connection.

Open the ShotGrid window with File → ShotGrid... in 3DE. It opens in the middle of your main screen and stays on top of 3DE.

Choosing Exit asks for confirmation first, because it sits right below File.

The very first time you start 3DE on a computer, it installs the ShotGrid components (PySide6, about 500 MB) in the background. That takes a few minutes and happens only once per computer. You can keep working; the ShotGrid menu works as soon as it is done.

The window

PartMeaning
SH010_010 The shot (or project) you are working in, with the project and type below it.
MATCHMOVE CAMTRACK The step and task from ShotGrid. NO TASK means 3DE was started at project level; pick a task with File Open first.
Open: … The .3de file that is open right now, or that the project has not been saved yet.

Shot Overview

Shot Overview lists every shot of the project with its thumbnail (the same thumbnails as the NFA Shot Manager in Nuke) and its matchmove status:

BadgeMeaning
PLATEA plate was found in 02_source; with more than one it says how many. NO PLATE: none yet.
UNDIST v2The newest undistorted plate in the plate's undistort folder.
TRACK v3The newest 3DE project (.3de) for this shot. NO TRACK: not tracked yet.
LUUK K.Who is on the Matchmove task. Your own name alone when you are one of them; otherwise NAME +1.

Shots without a thumbnail get one automatically: a Nuke runs in the background and makes it the same way the Shot Manager does, so both tools share the same pictures. You can keep working while it runs. A popup shows the progress; click Continue without thumbnails to stop it.

Pick a shot and click Open Shot (or double-click it): 3DE switches to that shot's Matchmove task and opens the newest track. Use My shots only to see just your own shots.

Loading a plate

Click Load Plate (only when started from a shot task). You see the plates of this shot from 02_source, with their frame range and whether an undistorted version already exists.

Pick a plate and click Load in 3DE. The plate is loaded as a camera with the settings from the Matchmove wiki: first frame 1001, 25 fps and gamma 2.2. You can change all three before loading.

Exporting to Nuke

Done undistorting in 3DE? Click Export to Nuke. The LD node of the selected camera is exported exactly like File → Export → Nuke LD_3DE4 Lens Distortion Node from the wiki, but straight to the right place and with the same version as your track:

04_publish/shots/<seq>/<shot>/<step>/nuke/…_LD_<name>_<camera>_v003.nk

The path is then on your clipboard. In Nuke, bring it in with File → Insert Comp Nodes. Save your 3DE project first (File Save), otherwise the tool does not know the version.

Undistorted plates

Undistorted plates are made in 3DE. Put them next to the original plate, in their own undistort folder with a version folder:

02_source/<seq>/<shot>/<plate>/undistort/v001/<plate>_undistort_v001.####.exr

So not in the plates folder itself: that holds only the original, so nobody mixes the two up by accident.

Where your files are

Work files:

03_workfiles/shots/<seq>/<shot>/<step>/3de/<project>_sc<seq>_<shot>_<step>_work_<name>_v001.3de

Publishes go under 04_publish/shots/…/3de/ with _pub_ in the name.

Tip: the NFA Shot Manager in Nuke shows a TRACK v3 badge per shot as soon as a .3de file sits in such a 3de folder.

Troubleshooting

There is no ShotGrid in the File menu

3DE was not started from ShotGrid Desktop. Close 3DE and start it again from ShotGrid Desktop.

My task is not in File Open → My Tasks

My Tasks only lists tasks assigned to you. Check in ShotGrid that you are in the task's Assigned To field. Omitted and approved tasks are hidden. You can always find any task through the Shots tab.

I click File → ShotGrid... and nothing happens

The engine could not start. Send %TEMP%\tk-3de4_debug.log to the pipeline TD. If the first-time install of the ShotGrid components failed, its log is %LOCALAPPDATA%\NFA\3de\pyside6\install_6.5.3.log.

File Save puts the file in the wrong folder

Check the task at the top of the window. If it is wrong, pick the right task with File Open.
